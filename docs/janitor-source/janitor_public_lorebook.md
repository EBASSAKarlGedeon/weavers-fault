# janitor_public_lorebook.dart

- **Path:** `C:/Users/Gedeon/Documents/Coding/Glaze-stable/lib/features/catalog/services/janitor_public_lorebook.dart`

- **Role:** Discovers a JanitorAI character's `scripts` lorebooks, downloads each public one whole, classifies it as plain-JSON / scripted-JS / closed, and converts JanitorAI's native entry shape into either a Glaze `Lorebook` or a SillyTavern World Info `.json`.

## Purpose

This is the "lorebook discovery + conversion" half of the port. Its central claim is structural: a JanitorAI character carries lorebooks as `scripts` in its metadata, and each script is either

1. **public JSON** — `GET /hampter/script/{id}` returns a `script` field that is a JSON *string* holding an array of entries: downloadable whole, 1:1 mapping, no LLM;
2. **public scripted ("advanced" / Nine API)** — the same endpoint's `script` field is **JavaScript source**, so the entries are generated by code and must be rebuilt by an LLM (see `janitor_lorebook_rebuilder.md`);
3. **closed** — the download yields nothing (403/empty), so the only route is prompt capture + LLM rebuild (see `janitor_extractor.md`, `janitor_separate.md`).

Dart port of JAR's `publiclore.js` + `worldinfo.js`. Two distinct conversion targets exist and both matter to us: `toLorebook()` (Glaze model) and `toTavernJson()` / `glazeLorebookToTavernJson()` (**SillyTavern World Info** — this is the shape our extension actually consumes, so the field list below is the most portable part of the file).

## Behaviour walkthrough

**Classification (`publicJsonBooks`, `publicJsBooks`, `closedLorebooks`, `downloadablePublicBooks`)**

Pure filters over a `List<PublicLorebook>`:

- `publicJsonBooks` → `b.accessible && !b.isJs`
- `publicJsBooks` → `b.isJs` (note: `isJs` alone; a JS book is reported as public because we hold the source)
- `closedLorebooks` → `!b.accessible && !b.isJs`
- `downloadablePublicBooks` → `[...publicJsonBooks(books), ...publicJsBooks(books)]` — "plain books first, then the scripted ones"; this is exactly the set the section's "Download all" converts and saves.

**Discovery (`lorebookScriptRefs`)**

Reads `meta['scripts']`; a non-List yields `const []`. Keeps only entries where `s['type'] == 'lorebook' || s['type'] == 'advanced'` **and** `s['id'] != null`; maps to `JanitorScriptRef(id: s['id'].toString(), title: (s['title'] ?? '').toString(), isPublic: s['is_public'] != false)`. So a missing `is_public` means *public* (fail-open), and `isPublic` is recorded but never used by this file's fetcher — every ref is fetched regardless.

**Fetching one book (`fetchPublicLorebook`)**

Never throws; every failure is encoded in the record.

1. GET `https://janitorai.com/hampter/script/<scriptId>` through `JanitorWebViewProxy.instance.fetch`.
2. If the decoded body is not a Map → `PublicLorebook(id: scriptId, title: title, error: 'response was not JSON')`.
3. Fetch the book's public page for its real description: `_fetchScriptDescription(scriptId)` GETs `https://janitorai.com/scripts/<scriptId>` and runs `_parsePublishedContent` on the HTML. Failure is logged as `[janitor-public-lore] scripts page <id> failed: <e>` and yields `''`, so the description falls back to the `/hampter` record's own `description` field, then to `''`. Both paths go through `_stripHtml`.
4. `entries = parseScriptEntries(rec)`; `usable` = count of entries that are Maps with non-empty trimmed `content`.
5. If `usable == 0`, try `_jsScriptSource(rec)`. If that yields non-empty JS, return a record with `isJs: true` and `jsSource` set (title from `rec['title'] ?? title`, `accessible` left at its default `false`).
6. Otherwise return `accessible: usable > 0`, `entryCount: usable`, `rawEntries: entries` (raw kept so callers can convert later without re-fetching).

**Page-description extraction (`_parsePublishedContent`)**

The lorebook's human description is **not** in the `/hampter` API (`description` there is usually empty); it lives on the `/scripts/{id}` page in the embedded store as `scriptPublishedContent.content`, with `script.description` as fallback. The page embeds that store as **escaped JSON inside a `window.mbxM.push(JSON.parse("…"))` call**, hence the double decode:

```
RegExp(r'JSON\.parse\("((?:[^"\\]|\\.)*)"\)')
```

For each match: `jsonDecode('"${m.group(1)}"')` (unescape the JS string literal) → `jsonDecode(jsonText)` → if the result is a Map, iterate **its values**; for each value that is a Map, look for `v['scriptPublishedContent']['content']` (non-empty trimmed String → return it), else `v['script']['description']` (same test). Returns `''` when nothing matches. This is a scrape; it will break silently if the page's bootstrap changes.

**`_jsScriptSource(rec)`**

Returns `''` unless `rec['script']` is a String; trims it; tries `jsonDecode` — if it parses **as a List** it is the structured shape, so return `''`; if decoding throws, the string is treated as JavaScript source and returned verbatim (trimmed). Note the asymmetry: a `script` that is a JSON *object* (not a list) is **not** excluded here, so it would be handed to the LLM as "JavaScript".

**`_stripHtml`** — the exact normalisation used for descriptions (mirrors the extractor's `_htmlToText`):

```
replaceAll(RegExp(r'<br\s*/?>', caseSensitive: false), '\n')
replaceAll(RegExp(r'</(p|div|li|h\d)>', caseSensitive: false), '\n')
replaceAll(RegExp(r'<[^>]+>'), '')
'&nbsp;'→' ', '&amp;'→'&', '&lt;'→'<', '&gt;'→'>', RegExp(r'&#39;|&apos;')→"'", '&quot;'→'"'
replaceAll(RegExp(r'\n{3,}'), '\n\n')
replaceAll(RegExp(r'[ \t]+'), ' ')
trim()
```

**Batch fetch (`fetchPublicLorebooks`)**

`@visibleForTesting Future<List<PublicLorebook>> Function(Map<String,dynamic>?)? debugFetchPublicLorebooks;` overrides the whole function when set (that is how tests run without a WebView platform). Otherwise: refs = `lorebookScriptRefs(meta)`, then **sequential** `await fetchPublicLorebook(ref.id, title: ref.title)` in ref order. No concurrency, no retry, no cancellation — N books cost N `hampter` calls plus N page calls, serialized through the proxy gate.

**Key-inference context (`buildLorebookDescsContext`)**

For each book: `title = b.title.trim()`, `desc = _stripHtml(b.description)`. Skip when both empty. Format: `'- <title>: <desc>'`, or `'- <title>'` when the description is empty; lines joined with `'\n'`. Contents are never included — only the public page description. This string is what `buildLorebookMessages` passes as the "CONTEXT — the public descriptions of lorebooks…" block.

**Public-entry subtraction (`publicEntryContents`)**

Flattens every entry `content` of every `!accessible == false` book into a `List<String>` (trimmed, non-empty only). Consumers subtract these verbatim strings from captured prompt text so public lore never leaks into the closed-lorebook extraction (`janitor_separate.dart:_stripPublicEntries` uses `loosePattern`).

**Raw download path (`rawLorebookEntries`)**

Splits captured plain text on `RegExp(r'\n\s*\n')`, trims, drops empties, and emits `{'content': block, 'comment': 'Entry <n>', 'key': <String>[]}` starting at `1` — i.e. keyless entries, so the "download raw" path produces a book with no triggers. Port of JAR `app.js` `downloadRaw`.

**Entry conversion (`_toEntry` / `convertJanitorScript`)**

Field tolerance chains, in order:

- keys: `key` ?? `keys` ?? `keysRaw` ?? `keywords`; via `_asKeys`: a List → each element `toString().trim()`; a String → `split(',')` then trim; anything else → `[]`.
- secondary: `keysecondary` ?? `secondary_keys` ?? `keySecondary`
- content: `content` ?? `text`
- comment: `comment` ?? `title` ?? `name` ?? `category` ?? `'Entry <index>'`
- probability: if num → `(raw <= 1 ? (raw*100).round() : raw.round()).clamp(0,100)`; else `100`. So `0.35` → 35 and `35` → 35; note that a genuine `1.0` probability is indistinguishable from "1%".
- `selectiveLogic`: num → int; **else 5** here (but `0` in the Tavern export — see below).
- `enabled`: `e['enabled'] != false && e['disable'] != true`
- `constant`: `e['constant'] == true`
- `position`: `_mapPosition(e['position'] ?? _placementPosition(e))`
- `order`: `_asOrder`: first numeric of `order`, `insertion_order`, `priority`; else `100`
- `caseSensitive`, `matchWholeWords`: only when the source value is a `bool`, else `null`
- `preventRecursion`: `e['prevent_recursion'] == true`
- entry id: `'jpl_${index}_${generateId()}'` (fresh random per conversion — not stable across runs)

`convertJanitorScript(entries, name:, characterId:)` skips non-Map entries and entries whose `content.trim()` is empty, then returns a `Lorebook` with `enabled: false` (never the Global switch), `activationScope: characterId != null ? 'character' : 'global'`, `activationTargetId: characterId`, `updatedAt: currentTimestampSeconds()`. The comment states the contractual rule: with a character ("Character + lorebooks") the book is registered character-scoped; without one ("Lorebooks" alone) it is saved switched off and the user decides.

**Position mapping (`_mapPosition`, `_placementPosition`)**

JanitorAI entries carry **no** `position`; instead `placement` can write the entry into a card field. Two mechanisms, in this precedence:

1. `_placementPosition(e)`: `placement == null || placement == 'default'` → null (entry keeps its own block). Otherwise `placementPosition == 'before'` → `'worldInfoBefore'`, else `'worldInfoAfter'`. The doc lists the writable fields as `personality`, `scenario`, `example_dialogs`.
2. `_mapPosition(pos)` (only reached when `e['position']` exists, since `??` prefers it): String `'before_char' | 'before_character' | 'worldInfoBefore'` → `'worldInfoBefore'`; `'at_depth' | 'lorebooksMacro'` → `'lorebooksMacro'`; anything else → `'worldInfoAfter'`. num `0 | 2 | 4` → `'worldInfoBefore'`; anything else → `'worldInfoAfter'`.

**SillyTavern export (`_tavernEntry`, `janitorScriptToTavernJson`, `_tavernPosition`, `glazeLorebookToTavernJson`)**

`_tavernPosition(pos)`: num → as-is (so 0..N pass through); `'before_char' | 'before_character' | 'worldInfoBefore'` → `0`; `'at_depth' | 'lorebooksMacro'` → `4`; default → `1`.

Each entry emits the full ST World Info field set (this is the block to copy verbatim into our exporter):

```
uid, key, keysecondary, comment, content,
constant, selective: !constant,
order, position, disable: e['enabled'] == false || e['disable'] == true,
displayIndex: uid, addMemo: true,
group: '', groupOverride: false, groupWeight: 100,
sticky: 0, cooldown: 0, delay: 0, probability,
depth: 4, useProbability: true, role: null,
vectorized: false, excludeRecursion: false, preventRecursion: e['prevent_recursion'] == true,
delayUntilRecursion: false, scanDepth: null,
caseSensitive (bool|null), matchWholeWords (bool|null), useGroupScoring: null,
automationId: '', selectiveLogic: <num|0>, ignoreBudget: false,
characterFilter: {isExclude: false, names: [], tags: []}
```

Entries with empty trimmed content are skipped, and `uid` increments **only for emitted entries** but `displayIndex`/`uid` therefore stay contiguous. Top-level result: `{ if (name.isNotEmpty) 'name': name, 'entries': { '<uid>': entry, … } }`.

`glazeLorebookToTavernJson(book)` emits the same shape from an already-built Glaze `Lorebook` (e.g. a closed book rebuilt by the LLM), reading `e.group`, `e.sticky`, `e.cooldown`, `e.delay`, `e.probability`, `e.scanDepth`, `e.caseSensitive`, `e.matchWholeWords`, `e.selectiveLogic`, `e.preventRecursion` and mapping position with `_glazeTavernPosition` (`worldInfoBefore`→0, `lorebooksMacro`→4, default→1). Always includes `'name'`, even when empty.

## Network / WebView contract

| Method | URL | Response |
|---|---|---|
| GET | `https://janitorai.com/hampter/script/<scriptId>` | JSON object; `script` is a JSON **string** (array) or JavaScript source |
| GET | `https://janitorai.com/scripts/<scriptId>` | HTML; description found via `JSON.parse("…")` in the page bootstrap |

Both via `JanitorWebViewProxy.instance.fetch(url)` (GET, `Accept: application/json, text/plain, */*`, `Bearer` token attached in-page, `credentials:"include"`, 25 s JS timeout, the proxy's queue/CF/401 retry ladder — see `janitor_webview_proxy.md`). No headers, params or bodies are added by this file. `_origin` is the literal `'https://janitorai.com'`.

There is no WebView *injection* here and nothing is read back from JS objects: the description extraction is regex-over-HTML on the returned body string.

## State machine, retries, timings

None. No timers, no attempts, no caches. The only persistence-like behaviour is the test seam `debugFetchPublicLorebooks`. Sequential fetching is the only ordering guarantee: books are processed in `scripts` order, and `downloadablePublicBooks` re-orders (JSON first, then JS) at the UI layer.

## Errors and user-visible messages

`fetchPublicLorebook` never throws: errors become `PublicLorebook.error` (either the literal `'response was not JSON'` or `e.toString()`) with `accessible: false`, and the UI then treats the book as closed. That is a deliberate conflation worth flagging: a transport failure is indistinguishable from a genuinely private book at this layer.

User-visible strings about these states live in the locale file, not here: `"catalog_lorebooks_public_hint": "Public, downloaded whole from Janitor.AI — no extraction needed."`, `"catalog_lorebooks_public_hint_scripted": "Scripted (advanced) books are shipped as a script, so they are rebuilt into entries with your active LLM."`, `"catalog_lorebooks_group_scripts": "Scripts"`, `"catalog_lorebooks_group_scripts_note": "Scripts need to be converted to lorebooks using an LLM."`, `"catalog_lorebooks_scripted_btn": "Rebuild with LLM"`.

## Porting notes for our SillyTavern port

- **Highest-value literal:** `_tavernEntry` is a complete, battle-tested mapping from JanitorAI entries to a SillyTavern World Info entry object. Our extension should emit exactly these keys with these defaults (`depth: 4`, `useProbability: true`, `addMemo: true`, `groupWeight: 100`, `selective: !constant`, `characterFilter` object). ST's `/api/worldinfo/edit`-style import expects this map, so this is close to copy-paste.
- **Reproduce literally:** the `scripts` type filter (`lorebook` | `advanced`) and the fail-open `is_public != false`; the `script`-is-a-JSON-string decode with its "parses as List ⇒ structured, throws ⇒ JavaScript" rule; the `JSON.parse("…")` page scrape (including the double decode); the `placement`/`placementPosition` semantics; `probability <= 1 ⇒ ×100`.
- **Do not reproduce:** `generateId()`-based entry ids (they change every conversion and would break our idempotent re-import), `currentTimestampSeconds()`, the `@visibleForTesting` seam, and the Dart `Lorebook`/`LorebookEntry` classes.
- **Fragile:** the HTML scrape of `/scripts/{id}` (silently returns `''` when the page changes — public lorebooks then lose their descriptions and key-inference quality drops without any error); `_jsScriptSource` accepting a JSON object as "JavaScript"; sequential N+1 fetching (2 requests per book, no cache — a character with 8 books costs 16 serialized proxy calls); `error != null` conflating "not JSON" with "private"; `selectiveLogic` default mismatch between the Glaze path (`5`) and the Tavern path (`0`).
- **One subtle bug to decide on:** `_asOrder`/`_tavernEntry` read `order` first, but JanitorAI's own field is usually `insertion_order`/`priority`; an entry carrying both a stale `order` and a meaningful `priority` will be ordered by `order`. Also `if (rawProb is num) … <= 1` means an entry with integer probability `1` becomes `100`, not `1`.
